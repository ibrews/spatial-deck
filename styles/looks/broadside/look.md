# Look: Broadside (`broadside`)

A letterpress broadside: newsprint stock, everything centered, a slab display face with a book serif, thick-thin rules and fleurons, one red second color. Use it for announcements, keynotes with a showman's energy, history talks, calls to action.

**Lineage.** 19th-century American letterpress broadsides, handbills and auction notices set in wood and metal type.

| Builder piece | In this look |
|---|---|
| Cover | Centered: event between rules, slab title, italic subtitle, a fleuron rule |
| Chapter | "Part N" kicker, slab title, italic lead, thick-thin rule |
| Two-pane case | Image in a double frame, toned to newsprint, pointing-hand bullets |
| Statement | Centered slab with a red eyebrow |
| Full bleed / grid | Toned images in ruled frames |
| Close | Ruled contacts |
| Motion graphics | Ink on newsprint, red accent; glow removed, screen becomes multiply |

**Motion grammar: press.** A short, firm impression; elements settle from 104% scale in .3 s. Reduced motion shows the final frame.

**Frame.** Thick-thin double rules across the top and bottom; project and page centered under them.

**Do** center everything and vary size line by line, as a compositor would. **Don't** use more than two faces or set a bullet list longer than four lines.
