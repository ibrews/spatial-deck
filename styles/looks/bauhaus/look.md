# Look: Bauhaus (`bauhaus`)

Dessau-era printed matter: cream stock, black, the three primaries, a geometric sans set lowercase, circle / square / triangle as structure. Use it for design education, design history, "first principles" talks, and talks about making things from simple parts.

**Lineage.** Bauhaus Dessau print shop (Herbert Bayer, László Moholy-Nagy, Joost Schmidt), 1925-32; Bayer's universal lowercase alphabet.

| Builder piece | In this look |
|---|---|
| Cover | A red disc and a blue bar compose the page, type flush left on the margin |
| Chapter | The number in a red circle, blue square or yellow triangle, cycling by section |
| Two-pane case | Bullets cycle circle, square, triangle |
| Statement | A heavy blue bar on the left edge |
| Full bleed / grid | Black labels, a red bar on full-bleed captions |
| Close | A yellow disc |
| Motion graphics | Primaries on cream; glow removed, screen becomes multiply |

**Motion grammar: build.** Shapes and type slide in from the left as if set on the press, .5 s, 180 ms stagger. Reduced motion shows the final frame.

**Frame.** A key of the three shapes with the page number, bottom left.

**Do** build each slide from at most one large shape and type. **Don't** use gradients, round the squares, or capitalize titles.
