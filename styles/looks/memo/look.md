# Look: Memo (`memo`)

A typewritten technical memorandum: one monospace, a SUBJECT / FROM / PAGE header, numbered paragraphs, a rubber-stamp red. Use it for postmortems, findings, technical deep dives, "here is what we learned" talks, and anything that should read as a document of record.

**Lineage.** Mid-century government and laboratory reports (NASA technical memoranda, RAND papers, office memos on a typewriter).

| Builder piece | In this look |
|---|---|
| Cover | The event as a rotated red stamp, the title in mono caps, XR underlined |
| Chapter | "Section N." kicker, title, lead in a long measure, a dashed rule |
| Two-pane case | Numbered paragraphs (1. 2. 3.), image boxed |
| Statement | Mono title with a ruled caption |
| Full bleed / grid | Boxed cells with tag labels |
| Close | Contacts in ruled boxes |
| Motion graphics | Ink on paper, red as the accent; glow removed, screen becomes multiply |

**Motion grammar: type.** Titles are typed on left to right in 28 steps over .9 s; copy fades in after. Reduced motion shows the final frame.

**Frame.** Memo header across the top: SUBJECT, FROM, PAGE, ruled under.

**Do** write slide copy as numbered findings. **Don't** use the stamp red for more than one element per slide.
