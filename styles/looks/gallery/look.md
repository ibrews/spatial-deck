# Look: Gallery (`gallery`)

An exhibition: a deep green painted wall, works hung in white mats with a thin brass line, chapters as room introductions, tombstone labels. Use it for portfolio reviews, case-study talks, retrospectives, anything image-led where the work should be hung, not decorated.

**Lineage.** Museum exhibition design: painted gallery walls, wall text and tombstone label conventions (artist, title, date, medium).

| Builder piece | In this look |
|---|---|
| Cover | Serif title, XR in italic brass, event as a small caps label |
| Chapter | "Room N" kicker, wall text in a narrow measure, a short brass rule |
| Two-pane case | The image in a white mat with a brass line; bullets set as a label, no markers |
| Statement | Italic serif |
| Full bleed / grid | Generous gutters, each cell matted, labels bottom right |
| Close | Contacts underlined in brass |
| Motion graphics | Warm white on green, brass accent; glow removed |

**Motion grammar: light.** Everything comes up slowly like gallery lighting, 1.1 s fade, 350 ms stagger. Reduced motion shows the final frame.

**Frame.** A small room label bottom left: project and page.

**Do** give images room and mats. **Don't** crowd a wall: one work per slide, two at most.
